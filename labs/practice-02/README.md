# Java Programming Fundamentals — University Lab 02

> Academic programming exercise from the Object-Oriented Programming course at UNAM.

## Overview

This repository preserves one of my early Java programming labs. The exercise explores console input, control flow, loops, and arrays. It is part of my university learning history rather than a production application.

## Topics covered

- Java console output and keyboard input
- Conditional statements (`if` and `switch`)
- Iteration (`while`, `do-while`, and `for`)
- One-dimensional arrays
- Basic methods and comparisons

## Files

| File | Description |
| --- | --- |
| `HolaMundo.java` | Main exercise demonstrating the programming concepts above. |
| `KeyboardInput.java` | Helper class used for console input. |

## Running the exercise

The source declares the package `com.mycompany.mpoop2`. Place the Java files in a matching package directory within a Java project, then compile and run `HolaMundo` using a compatible JDK.

The code is retained in its original academic form, including commented examples.

## Learning context

This work documents foundational programming practice that preceded my later projects in data analysis, SQL, and automation.
