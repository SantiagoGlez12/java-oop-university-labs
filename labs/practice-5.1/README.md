# Encapsulation and Composition — Extended University Lab 05

> Extended version of a Java exercise on classes and object composition.

## Overview

This lab models circles, people, dates, and cars. Its source demonstrates getters and setters, construction of related objects, and assigning people to a vehicle as driver and passengers.

## Contents

- `Main.java` — demonstration of the objects and their relationships.
- `Circulo.java`, `Persona.java`, `Fecha.java`, `Coche.java` — supporting classes.

## Learning context

This is a revised companion to [MPOOP5](../practice-05), not an independent production application. It is included as a separate variant in this consolidated collection.
