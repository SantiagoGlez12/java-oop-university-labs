# Encapsulation and Object Composition — University Lab 5

> Historical Java coursework from my Object-Oriented Programming studies at UNAM.

## Overview

This repository preserves a university exercise exploring **encapsulation and object composition**. The original files are retained as a record of how my software development skills progressed during my degree.

## Concepts practiced

- Getters and setters
- Modeling objects with related classes
- Composition using Person and Date objects
- Associating passengers and a driver with a Car
